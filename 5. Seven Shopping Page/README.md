How to Run the Project-:
1. Download or clone the project to your computer.
2. Open the project folder in VS Code.
3. Make sure all the files are present in the same folder:
index.html
product.html
cart.html
payment.html
style.css
4. Open index.html in VS Code.
5. You can run the project in either of these ways:
6. Using Live Server: Right-click index.html → Open with Live Server.
7. Without Live Server: Double-click index.html to open it directly in your browser.
8. Use the navigation bar to move between the different pages:
Home → Landing Page
Products → Product Display Page
Cart → Shopping Cart
Contact/Checkout → Payment Page
