# Omnifood 🍽️

Omnifood is a modern, responsive food delivery website that promotes healthy eating through nutritious meals and convenient meal plans.

🔗 **Live Demo:** https://eatfromomnifood.netlify.app/

## ✨ Features
- Clean and attractive user interface
- Responsive design for different devices
- Healthy meal showcase
- Meal subscription and pricing plans
- Customer testimonials
- Interactive navigation

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download the project files.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the **Live Server** extension for a better development experience.
