# Greenwood Public Library Website

A modern, responsive website concept for Greenwood Public Library. The design
uses an editorial layout, warm neutral colors, forest-green sections, and
library photography.

## Features

- Sticky navigation with a blurred background
- Responsive mobile navigation menu
- Large hero section with library imagery
- Library statistics and introduction section
- Six collection/category cards
- Editorial bento-style content grid
- Membership pricing cards
- Community testimonial section
- Events and activities section
- Contact and visit information
- Footer with automatic current year
- Scroll-reveal animations
- Hover effects on image cards
- Reduced-motion accessibility support
- Responsive layouts for desktop, tablet, and mobile

## How to Run the Project

### Option 1: Open directly

1. Download or copy the project files.
2. Open the project folder.
3. Double-click `index.html`.
4. The website should open in your default browser.

### Option 2: Run using Visual Studio Code

1. Install Visual Studio Code.
2. Open the `greenwood-library-project` folder.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. The website will open in your browser.

## Customization

You can personalize the website by editing `index.html`.

### Change the library name

Search for `Greenwood Public Library` or `Greenwood` and replace it with
your preferred library name.

### Change the colors

The main colors are defined using Tailwind classes and custom CSS.

- Forest green: `#24372d`
- Warm cream: `#f7f5ef`
- Muted gold: `#e4bd8d`
- Sage green: `#d8e0d4`

### Change images

Replace the Unsplash image URLs in the `<img>` elements with your own
image URLs.

### Change contact details

Update the sample address, opening hours, and email in the contact section.

### Change events and membership plans

The event names, dates, membership fees, and benefits are example content.
Replace them with accurate information before publishing.

## Important Notes

- An internet connection is required for Tailwind CSS and the remote images.
- The contact email uses a placeholder address and must be replaced.
- The membership buttons are design elements; no payment system is connected.
- The website does not currently have a database, login system, or book
  reservation backend.
- Event information and membership prices are illustrative placeholders.
